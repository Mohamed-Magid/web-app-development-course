3. HTML Links (Anchor Tag)

The <a> tag defines a hyperlink: <a href="URL">Link Text</a>

Main attributes: href (destination), target (where to open), title (hover info), download (download the file), rel (page relationship).

7. HTML Forms

Forms collect information from users: login, registration, contact, search. <input> collects user data, <label> describes the field, <button> submits the form.

8. <input> vs <label>

<input>: accepts user input - self-closing, no inner content; attributes: type, name, value, placeholder, required.

<label>: descriptive text for an input; clicking it focuses the input whose id matches the label's for attribute:
