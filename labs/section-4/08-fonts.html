CSS Fonts

Fonts improve readability and user experience: choose a clear font style, a comfortable size, and adequate spacing.

font-family

font-family: Arial, Helvetica, sans-serif; (the browser tries each font in order until one is available)

font-size

font-size: 32px; (common units: px, em, rem, %)

font-weight

font-weight: bold; (values: normal, bold, lighter, 100-900)

font-style

font-style: italic; (values: normal, italic, oblique)

Font Shorthand

font: italic bold 20px Arial, sans-serif; (style, weight, size, family - all in one line)
