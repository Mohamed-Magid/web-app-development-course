1. What is CSS?

Cascading Style Sheets - a stylesheet language that controls the visual presentation of web pages. It controls appearance of elements, manages layout and spacing, and separates content (HTML) from design (CSS). This whole page is the "after" picture: without CSS it would be plain black text on white.

2. Three Ways to Add CSS

Inline CSS - inside the element with the style attribute: this text is styled inline. Styles apply only to that element - quick to test, hard to maintain.

Internal CSS - inside a <style> tag in the <head>. That is how THIS page is styled: one place, applies to the whole document, but cannot be shared with other pages.

External CSS - a separate .css file linked with <link rel="stylesheet" href="style.css">. Reusable across pages, clean, and the industry standard. See it in action: 04-external-css.html (powered by style.css).

3. CSS Syntax

Every rule follows the same structure: selector { property: value; }

Example: p { color: blue; font-size: 18px; } - the selector is p, the properties are color and font-size, blue and 18px are the values.

4. CSS Selectors (Element, Class, ID)

Element selector - h2 { color: #1a5276; } targets every <h2> on this page (all the section titles share its color).

Class selector - starts with a dot and is reusable: .highlight { background-color: yellow; } and .note { color: darkgreen; } are used in several places on this page.

ID selector - starts with # and targets ONE unique element: the intro paragraph at the top uses #intro { font-size: 18px; }. Each ID should appear only once per page.

5. Colors in CSS

Three methods, same red:

color: red; (color name)

color: rgb(255, 0, 0); (RGB values, 0-255 per channel)

color: #FF0000; (HEX code, format #RRGGBB)

6. CSS Fonts

This page sets font-family: Arial, Helvetica, sans-serif; on the body - the browser tries each font in order (fallback list).

font-size: 24px; font-weight: bold; (sizes can use px, em, rem, %)

Shorthand: font: italic bold 20px Arial, sans-serif; (order: style, weight, size, family - size and family are required)

8. CSS Priority (Specificity)

When multiple rules target the same element, the browser picks by priority.

By source: inline CSS (highest) > internal CSS > external CSS (lowest). This text has an inline style that overrides everything else.

By selector: ID (highest) > class > element (lowest). The paragraph below is targeted by all three - and the ID wins:

p says green, .winner says blue, #winner says red - so I am red.
