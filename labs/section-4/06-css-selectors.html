CSS Selectors

Element Selector

h2 { color: red; } targets every <h2> on the page. Best for base typography styles - simple and broad-reaching.

Class Selector

This paragraph uses class="highlight" - styled by .highlight { background-color: yellow; }.

The same class is reused here - classes are meant to be applied to multiple elements.

ID Selector

The page title above uses id="main-title" - styled by #main-title { color: blue; }. An ID must be unique on the page; if you need to style multiple elements, use a class instead.
