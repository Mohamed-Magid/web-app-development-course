HTML Attributes

Attributes provide additional information about HTML elements. They are always placed inside the opening tag.

Attribute Structure

attribute="value"

Image Example (from the lecture slide)

<img src="image.jpg" alt="profile image">

The src Attribute

Slide example: src="images/photo.jpg"

This page uses a local file: src="profile.jpg"

The alt Attribute

Example: alt="Company logo"

If an image fails to load, the browser shows the alt text instead. Remove the working src above and reload to see it in action.

Common Attributes

href — link destination: Visit Example

id — unique identifier: This element has a unique id.

class — CSS styling class: This element belongs to classes "box" and "highlight".

style — inline CSS: This text is styled inline.
