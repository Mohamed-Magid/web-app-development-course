id vs class in HTML

Using id — one unique element

This div has id="header" — there can be only one like it.

Using class — group multiple elements

Box 1 — class="box highlight"
Box 2 — class="box"
Box 3 — class="box highlight"

Comparison

Uniqueness: id must be unique in the page; class can be used on multiple elements.

Purpose: id identifies a single element; class groups multiple elements.

CSS selector: #idName vs .className

JavaScript access: getElementById("idName") vs getElementsByClassName("className")

Multiple values: an element cannot have multiple ids, but it can have multiple classes, e.g. <div class="box highlight">

Use id when you need one unique element. Use class when you need to apply styles or scripts to many elements.
