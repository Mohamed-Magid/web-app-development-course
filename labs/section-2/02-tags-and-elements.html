HTML Tags and Elements

HTML uses tags to define elements on a webpage.

Element Structure

<tag> Content </tag>

Parts of an Element

Opening tag <p> — marks the beginning of the element.

Content — everything between the opening and closing tags.

Closing tag </p> — marks the end of the element (with a forward slash).
