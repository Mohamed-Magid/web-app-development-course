1. HTML Document Structure

Every HTML page uses this structure:

<!DOCTYPE html> declares HTML5
<html> is the root element
<head> holds metadata (like <title>, shown in the browser tab)
<body> holds all visible content

Check this browser tab - it shows this page's <title>.

2. HTML Tags and Elements

An element = opening tag + content + closing tag:

<p> This is the content. </p>

The opening tag starts the element, the closing tag (with a forward slash) ends it, and everything in between is the content.

3. HTML Attributes

Attributes provide extra information and always go inside the opening tag: attribute="value"

src (image file location) + alt (image description for accessibility):

<img src="image.jpg" alt="profile image"> — if the image fails to load, the alt text is shown instead.

href on a link: Visit Example

style (inline CSS): Blue text via the style attribute.

4. id vs class

id="header" - unique, identifies ONE element (CSS: #header)
class="box" - can be reused on MANY elements (CSS: .box)
class="box highlight" - an element can have multiple classes

id: getElementById("idName") | class: getElementsByClassName("className")
