# Web App Development Course

Lab exercises for the **Web Application Development** course (Fourth Year).

Each section has its own folder with numbered topic files plus a combined
`index.html` showcase that demonstrates every topic from the lecture on one
page. Open the `index.html` of any section in a browser to browse the lab.

## Labs

| Section | Topic | What it covers |
|---------|-------|----------------|
| [Section 2](labs/section-2/index.html) | HTML Basics | Document structure, tags & elements, attributes, id vs class, headings, paragraphs, text formatting, comments |
| [Section 3](labs/section-3/index.html) | HTML Elements | Lists, links, images, tables, forms, input types, registration form |
| [Section 4](labs/section-4/index.html) | CSS Basics | Inline / internal / external CSS, syntax, selectors (element, class, ID), colors, fonts, backgrounds, CSS priority (specificity) |

## How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/Mohamed-Magid/web-app-development-course.git
   ```
2. Open any lab's `index.html` in your browser.
3. Use the links on that page to jump between the separate topic files.

Each section ends with an assignment file containing a worked solution.
