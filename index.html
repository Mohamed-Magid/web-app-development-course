Web App Development Course

Lab exercises for the Web Application Development course (Fourth Year). Each lab combines every topic from its lecture on one showcase page, with links to separate topic files and a worked assignment solution.

Section 2 - HTML Basics

Document structure, tags & elements, attributes, id vs class, headings, paragraphs, text formatting, comments.

Section 3 - HTML Elements

Lists, links, images, tables, forms, input types, registration form.

Section 4 - CSS Basics

Inline / internal / external CSS, syntax, selectors, colors, fonts, backgrounds, CSS priority (specificity).
